# Project Context: Endless Car Dodge (Python)

## Profile

* **Developer:** Git
* **Role:** Software Engineering Student @ Telkom University
* **Focus:** Mobile-style 2D Games, Backend Development, Automation.

## Project Overview

Permainan "Endless Car Dodge" adalah game mobile sederhana dengan POV dari atas (Top-Down). Mekanismenya menyerupai 'Dino Run' tetapi dengan kontrol arah kiri/kanan untuk mengelak trafik.

## Technical Stack

* **Language:** Python 3.x
* **Library:** Pygame
* **Assets:** - Player: `mobil\_player.png`

  * Enemies: `mobil\_1.png` hingga `mobil\_10.png`

## Coding Standards \& Preferences

* **Structure:** Gunakan Object-Oriented Programming (OOP) dengan Sprite Class untuk setiap entitas.
* **Scaling:** Implementasikan peningkatan kesukaran (kecepatan) secara berkala berdasarkan masa bertahan.
* **Robustness:** Pastikan terdapat fungsi 'fallback' (warna solid) jika aset imej tidak ditemui supaya aplikasi tidak crash.
* **UI:** Gunakan font sistem yang bersih dengan paparan skor yang real-time.

## Current Goal

Membangunkan MVP (Minimum Viable Product) yang stabil dengan sistem collision yang tepat dan sistem restart yang lancar.
